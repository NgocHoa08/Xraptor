# Xraptor - Website Pickleball

Giao diện website thương mại điện tử vợt & phụ kiện Pickleball thương hiệu **Xraptor**, được clone chuẩn pixel từ thiết kế Figma:
- **Tech stack**: React 19, Vite, Tailwind CSS v4, Lucide Icons
- **Các trang**:
  - Trang chủ (Hero slider, Danh mục, Sản phẩm nổi bật, Về Xraptor, Phụ kiện theo phân loại, Phản hồi khách hàng & Video review, Blog - Tin tức)
  - Phụ kiện Pickleball (Bộ lọc dòng vợt & phụ kiện, Sắp xếp theo giá/tên, Phân trang, Sản phẩm đã xem)
  - Chi tiết sản phẩm (Bộ sưu tập ảnh, Thông số kỹ thuật, Cam kết chính hãng, Mô tả sản phẩm mở rộng, Sản phẩm tương tự)
  - Liên hệ (Form liên hệ, Thông tin Hasuko & Hotline)
  - Giỏ hàng trượt (Thêm/bớt số lượng, xóa sản phẩm, tính tổng đơn hàng)

## Cài đặt & Chạy dự án

```bash
# Cài đặt thư viện
npm install

# Chạy môi trường phát triển (Dev)
npm run dev

# Đóng gói xuất bản (Build)
npm run build
```
